
Marshall Acton III Keep-Alive (Windows Tray Utility)

Легковесная фоновая утилита для Windows, которая предотвращает автоматическое отключение Bluetooth-колонки Marshall Acton III при отсутствии звука на ПК.

Зачем это нужно?

В колонке Marshall Acton III встроена функция энергосбережения, которая переводит устройство в спящий режим ровно через 10 минут тишины. При подключении к компьютеру по Bluetooth это создает неудобство: чтобы звук снова появился, приходится каждый раз переподключаться к колонке вручную.
Эта утилита работает в системном трее и каждые 4 минуты отправляет на колонку короткий (1 сек) неслышимый для человеческого уха низкочастотный звуковой импульс (15 Гц), сбрасывая таймер автоотключения.

Основные возможности

• Никаких лишних зависимостей: написано на чистом PowerShell и .NET — не требует установки Python, сторонних библиотек или драйверов.
• Умное определение устройства: автоматически проверяет, подключена ли колонка в данный момент, и не отправляет импульсы впустую, если она выключена.
• Индикация в системном трее: наглядный статус работы через цвет иконки возле часов:

	• 🟢 Зеленый — колонка подключена, утилита активна и поддерживает соединение.
	• 🟠 Оранжевый — утилита запущена, но колонка не найдена или отключена (режим ожидания).
	• 🔴 Красный — работа поставлена на паузу пользователем.
	
• Контекстное меню: отображает точное системное имя найденного устройства, позволяет ставить скрипт на паузу, запускать заново и корректно завершать работу.
• Готовность к компиляции: легко собирается в автономный .exe без окна консоли для добавления в автозагрузку Windows.

Запуск и сборка в .exe


1. Прямой запуск скрипта

Откройте PowerShell и выполните:
powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "keepalive_tray.ps1"
Используйте код с осторожностью.

2. Компиляция в .exe (без окна консоли)

Для создания автономного исполняемого файла используйте модуль ps2exe:
powershell
Install-Module ps2exe -Scope CurrentUser
Invoke-ps2exe -inputFile "keepalive_tray.ps1" -outputFile "ActonKeepAlive.exe" -noConsole
Используйте код с осторожностью.

3. Добавление в автозагрузку Windows

1. Нажмите Win + R, введите shell:startup и нажмите Enter.
2. Поместите ярлык на скомпилированный файл ActonKeepAlive.exe в открывшуюся папку.

Настройка под другие колонки

Утилита подойдет для любой другой Bluetooth-акустики с агрессивным режимом энергосбережения (JBL, Harman Kardon, Edifier и др.). Достаточно изменить имя устройства в первой секции скрипта:
powershell

$TargetDevice = "ACTON III" # Укажите часть названия вашей колонки

$IntervalSeconds = 240      # Интервал отправки импульса в секундах
